# JavaScript — Array Methods & Destructuring

Six **independent** coding exercises. Nothing is merged into one page or script.

## How to run

Open one of the `.js` files in PyCharm or another editor. To run it in a terminal:

```bash
node Exercise_1_Colors.js
```

Replace the filename for each exercise. These exercises use `console.log()` only; they do not require HTML, CSS, or browser APIs such as `document` or `prompt`.

## Exercise index

1. **Colors** — `forEach`, `some`, template strings and index numbers.
2. **Colors #2** — `forEach`, ordinal suffixes, ternary operator.
3. **Analyzing** — array/string spread, predicted outputs, sparse array holes.
4. **Employees** — `map`, `filter`, method chaining and object destructuring.
5. **Star Wars** — `reduce`, accumulators and spacing.
6. **Employees #2** — `filter`, `forEach` and object destructuring.

## How to study

Read the `STRATEGY` comment at the beginning of a file; predict its output;
run the file; and then explain in your own words why the chosen array method
fits the task. Try changing the data and predicting how the output changes.

## Key distinction

- `map()` returns a new array of transformed values.
- `filter()` returns a new array of matching elements.
- `some()` returns a boolean.
- `reduce()` combines values into one result.
- `forEach()` runs an action for every element and returns `undefined`.

## Scope

The examples use exactly the provided exercise arrays and complete all stated bonuses.
No DOM page is needed because all requested output goes to the console.
