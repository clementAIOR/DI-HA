# Exercise 7 — Welcome

The navbar is written in `index.html`. The IIFE in `script.js` accepts the user's name, creates a `div`, an `img`, and a `span`, and attaches them to the navbar.

- **`document.createElement()`** makes real HTML elements.
- **`classList.add()`** assigns a CSS class.
- **`appendChild()`** inserts an element into another element.
- **`textContent`** inserts a username as text instead of HTML (which is safer).

An `avatar.svg` profile illustration is provided locally, so the page works without an internet connection.
