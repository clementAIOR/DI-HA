# Exercise 5 — Kg and Grams

All three functions perform `kg * 1000`, so calling them with `2.5` should produce **2500** grams.

A **function declaration** is available earlier in its scope because its declaration is hoisted. A **function expression** stored with `const` cannot be called before that variable is initialized. An **arrow function** is another way to write a function expression, often shorter for small calculations.
