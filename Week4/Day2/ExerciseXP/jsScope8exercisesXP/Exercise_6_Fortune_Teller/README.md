# Exercise 6 — Fortune Teller

This is an **IIFE**: Immediately Invoked Function Expression.
```js
(function (first, second) {
    // use both parameters
})(value1, value2);
```
The first parentheses make a function expression, and the final parentheses immediately run it with arguments.

Template literals (backticks) let you insert values with `${variable}`. The resulting sentence is written to the DOM using `textContent` to avoid treating the content as HTML markup.
