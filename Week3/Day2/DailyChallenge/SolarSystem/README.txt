Solar System project

EASIEST METHOD:
Open SolarSystem.html in Chrome. This one file works by itself; no JavaScript file is needed.

FOR EDITING WITH SEPARATE FILES:
Keep Testing.html and script.js in the same folder, then open Testing.html in Chrome.
Edit script.js in PyCharm or VS Code and refresh the browser to see changes.

If your browser cannot download .js files, download script.txt, rename it to script.js, and put it next to Testing.html.
